# MD Convert

Transform your PDFs, ebooks, captures, Word documents, notes, and transcripts into clean files for AI and your second brain.

**[Open MD Convert →](https://sebastien-riviere.github.io/outils/MD-Convert/)**

No installation. No account. Your files never leave your device.

---

## Supported formats

| Format | Type | Quality |
|---|---|---|
| PDF | Native text | Excellent |
| Scanned PDF / ebook PDF | Automatic OCR | Good (depends on scan sharpness) |
| DOCX / DOC | Word | Very good |
| JPG / PNG / WEBP | Image + OCR | Good (sharp printed text) |
| Smartphone capture | Photo OCR | Good (sharp, well-framed text) |
| TXT / MD | Plain text | Perfect |
| Pasted text | Copy-paste | Perfect |
| YouTube (URL) | Automatic transcript | Good (if captions available) |
| Web article (URL) | Text import | Good (if page not blocked) |
| Public Google Doc (URL) | Text import | Very good |
| GitHub file (URL) | Text import | Perfect |

---

## Features

- Local and offline conversion — zero server upload
- Built-in OCR for images and photos (Tesseract.js)
- Automatic image preprocessing before OCR
- OCR confidence indicator per file
- Selectable OCR language: FR / EN / FR+EN
- Batch processing — multiple files or entire folder
- Individual export or global ZIP
- File merge into a single document
- Preview before download
- One-click copy
- Output file renaming
- Token estimation (MD Convert vs raw document)
- Dark / light mode
- Installable PWA on iPhone, Android, and desktop
- Fully offline after first load

## Typical use cases

**For AI (Claude, ChatGPT, Gemini…)**
- Prepare a PDF or ebook as structured Markdown before submitting it
- Clean up a Word document to reduce noise in the context window
- OCR a smartphone capture to make it searchable
- Reduce token count without losing useful information

**For your second brain (Obsidian, NotebookLM, Notion…)**
- Convert scattered sources into clean, reusable notes
- Consolidate multiple documents into a single Markdown file
- Extract text from images and photographed pages

## URL import

The tool accepts URLs directly in the import panel:

- **YouTube** — paste the video link; the transcript is fetched automatically if captions are available. If it fails, paste the transcript manually into the text field.
- **Web articles** — text import via [Jina.ai](https://jina.ai) (internet connection required). Some pages may be blocked.
- **Public Google Docs** — direct import of exported text.
- **GitHub** — import raw file from `github.com` or `raw.githubusercontent.com`.

> For fully offline or private use, copy-paste the text directly into the dedicated text field.

---

## Token estimation

Each converted file shows a token count estimate:

- **Green** — estimated tokens for the Markdown generated by MD Convert
- **Orange** — estimated tokens if the raw document were sent as-is to an AI

These values are indicative (local approximation, no data sent).

## Install as an app (PWA)

**iPhone / iPad**
1. Open the link in Safari
2. Share button → "Add to Home Screen"
3. The app appears as a native app

**Android**
1. Open the link in Chrome
2. Banner or menu → "Install"
3. Works offline afterwards

---

## Offline support

On first load, conversion libraries are cached by the browser. From the second launch onwards, the tool works entirely offline — including in airplane mode.

Exception: OCR language models (Tesseract) are downloaded once on first image use, then also cached.

## Known limitations

- **Scanned PDF**: OCR quality varies with scan sharpness
- **Very large files**: local processing is limited by browser RAM; recommended < 50 MB per file
- **PPTX**: not supported in v1 — export as PDF from PowerPoint before importing
- **Google Slides / Sheets**: not directly supported — export as PDF or copy-paste the text
- **Audio / video**: audio transcription not supported
- **Handwritten text**: approximate results with Tesseract
- **Folder selection**: not available on Safari iOS (multiple file import works fine)
- **Web pages**: some pages block automatic imports; use copy-paste in that case
