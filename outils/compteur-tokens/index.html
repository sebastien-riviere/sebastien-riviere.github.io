Comment lire le découpage : ␣ = espace, ⏎ = retour à la ligne. Un mot courant = souvent 1 token ; un mot rare ou accentué se coupe en plusieurs (ex. unité → unit+é). C'est pour ça que le français coûte ~20-40 % de tokens de plus que l'anglais.
Fiabilité : les comptes sont exacts pour les modèles OpenAI (GPT-4 = cl100k, GPT-4o = o200k). Claude, Gemini, Llama et Mistral utilisent d'autres tokenizers — pour eux, ce compteur donne un ordre de grandeur, pas le chiffre exact. Les prix évoluent : le champ « prix / 1 M » est modifiable, vérifie le tarif officiel de ton modèle.
