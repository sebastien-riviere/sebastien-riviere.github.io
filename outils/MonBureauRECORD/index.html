Comment ça marche

Comment enregistrer une réunion, baliser les passages importants et générer un compte rendu.

Parcours en 3 étapes
  1. 1
    Enregistrer ou importer

    En capture live, le navigateur enregistre votre écran en segments vidéo horodatés. Chaque segment est finalisé et sauvegardable dès sa fin — si le navigateur plante, vous ne perdez que le segment en cours. En import, vous ouvrez un fichier déjà existant (réunion Zoom, screencast, entretien…).

  2. 2
    Baliser les moments importants

    Touche S pour capturer une image de l'écran au moment précis. Touche M pour poser un repère temporel nommé. Les captures automatiques (toutes les N secondes) produisent un stock d'images exploitables sans action manuelle — idéal pour générer un rapport complet d'une longue session.

  3. 3
    Produire les livrables

    Le PDF illustré rassemble toutes vos captures dans un document A4 prêt à partager. Le pack NotebookLM exporte la timeline + notes + questions suggérées pour analyse IA. La timeline HTML est une page web autonome partageable par mail. Le ZIP complet archive tout — vidéos, captures, scripts de conversion.

Questions fréquentes
Pourquoi mes vidéos sont en .webm ?

WebM est le format natif du navigateur pour l'enregistrement. Pour obtenir du MP4 universel, utilisez le script FFmpeg fourni dans la section « Convertir en MP4 ».

Pourquoi pas de transcription automatique ?

L'app reste 100% locale, sans IA, sans appel réseau. Pour transcrire, utilisez un outil local comme Whisper après avoir converti en WAV 16 kHz (script fourni).

Mes vidéos ont disparu après refresh, pourquoi ?

Les fichiers vidéo .webm sont gardés en mémoire vive pendant la session, mais ne sont pas conservés dans votre navigateur après fermeture (trop volumineux). Téléchargez-les ou générez le ZIP avant de fermer.

Quels navigateurs sont compatibles ?

Chrome, Edge, Brave (recommandés). Firefox fonctionne pour la lecture. Safari ne supporte pas l'API getDisplayMedia complète.

Comment installer l'app sur mon téléphone ?

Sur Android (Chrome) : menu ⋮ → « Ajouter à l'écran d'accueil ».
Sur iPhone (Safari) : bouton Partager → « Sur l'écran d'accueil ». L'app fonctionnera ensuite hors-ligne, comme une application native.

macOS dit « app non identifiée » quand je télécharge un script .sh

C'est Gatekeeper, la sécurité macOS qui bloque par défaut les scripts d'origine inconnue. Solution : clic droit sur le fichier .sh → « Ouvrir », puis confirmer. Alternative plus simple : ouvrir Terminal et taper bash chemin/du/script.sh.

Pour les fichiers .md, .html ou .json, ce blocage ne devrait pas survenir — si c'est le cas, ouvrez-les directement avec votre éditeur (TextEdit, Obsidian, VS Code) via clic droit → « Ouvrir avec ».
