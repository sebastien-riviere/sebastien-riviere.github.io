Prendre Claude en main

Guide pour débuterÀ jour juin 2026~15 min

Vous débutez avec Claude ? Ce guide vous accompagne pas à pas : choisir le bon modèle, paramétrer votre assistant dans le bon ordre, comprendre les différents Claude, et garder les bons réflexes. Avec des prompts prêts à copier-coller.

1. Les trois Claude

« Claude » se décline en trois produits. Pour débuter, vous n'avez besoin que du premier — les deux autres viendront si le besoin se présente.

Claude (web & appli)
Le point de départ

Sur claude.ai et l'appli mobile/bureau. Pour discuter, écrire, analyser des documents, créer des assistants. 95 % des usages commencent ici.

Claude Cowork
Vos fichiers

Claude qui agit dans vos fichiers (ordinateur, Google Drive) : organiser, renommer, créer et éditer des documents en lot — ce que le chat ne fait pas.

Claude Code
Technique

Claude dans le terminal, pour le code et les projets techniques (sites, scripts, automatisations). Plutôt pour makers et développeurs.

Si vous débutez : restez sur Claude (web & appli). Tout le reste de ce guide s'y applique.

2. Démarrer

Créer son compte

Rendez-vous sur claude.ai. L'offre gratuite suffit pour tester ; l'offre payante (Pro, ~20 €/mois) débloque plus d'usage et les fonctions avancées (Projets, connecteurs…).

Choisir le modèle

Un « modèle » = le cerveau que vous utilisez. Trois grands profils :

ModèlePour quoiQuand le choisir
OpusLe plus puissant : raisonnement, tâches complexes, rédaction exigeanteQuand la qualité compte vraiment
SonnetÉquilibré et rapideVotre usage quotidien par défaut
HaikuUltra-rapide, légerTâches simples, réponses courtes
Réflexe débutant : Sonnet par défaut, Opus quand l'enjeu est élevé. Vous changez de modèle en un clic en haut de la conversation.

Et la « consommation » (tokens) ?

Chaque échange « consomme » une certaine quantité de texte (les fameux tokens). Bien la gérer = des réponses meilleures et moins de blocages. J'en ai fait un guide dédié : Vos tokens Claude, c'est précieux →

3. Paramétrer son assistant, dans l'ordre

Cinq étapes, du plus simple au plus avancé. Faites-les dans cet ordre — vous pouvez vous arrêter à l'étape 3 et déjà gagner un temps fou.

1

Vos instructions personnelles

Dites une fois pour toutes à Claude qui vous êtes et comment vous voulez ses réponses : il s'y conforme dans toutes vos conversations.

Où : Réglages → Profil / Instructions personnalisées
Je m'appelle [Prénom]. Je suis [métier / activité].
Mes objectifs : [ex. gagner du temps sur X, produire Y].

Comment je veux que tu répondes :
- en français, clair et concret, sans jargon ;
- va droit au but ; quand je dois décider, propose une reco ;
- si tu n'es pas sûr, dis-le plutôt que d'inventer.

Mes sujets récurrents : [vos domaines].
2

La mémoire

Activez la mémoire pour que Claude retienne vos informations récurrentes (votre métier, vos préférences) d'une conversation à l'autre — sans tout répéter.

Où : Réglages → Mémoire (activer)
Vous gardez la main : la mémoire se consulte, se modifie et s'efface à tout moment.
3

Votre premier Projet

Un Projet est un espace dédié où vous déposez vos fichiers et des instructions. Toutes les conversations à l'intérieur réutilisent ce contexte. (Détails à l'étape suivante.)

Où : menu Projets → Nouveau projet → ajouter des instructions + des fichiers
Contexte de ce projet : [à quoi il sert].
Qui je suis : [métier, niveau].
Dans les fichiers, tu trouveras : [cours, modèles, notes…].

Ta mission ici :
- t'appuyer en priorité sur les fichiers fournis ;
- signaler quand une info n'y est pas (ne pas inventer) ;
- garder mon style : [décrire en un mot].

Format préféré : [ex. listes courtes, titres clairs].
4

Les Skills (capacités)

Les Skills sont des savoir-faire que Claude applique sur demande (mettre en forme un document, suivre une procédure que vous lui avez apprise…). Activez celles qui servent vos usages — inutile de tout activer.

Où : Réglages → Capacités / Skills
5

Les connecteurs (vos outils)

Les connecteurs branchent Claude à vos outils (Google Drive, Agenda, Gmail, Canva, Notion…) : il peut alors lire et écrire dedans, et même agir pour vous. L'annuaire en compte plus de 50. C'est l'un des points forts de Claude aujourd'hui.

Où : bouton « Personnaliser » dans la barre latérale → Connecteurs → + (Parcourir les connecteurs)
Prudence données sensibles : ne branchez pas un connecteur sur des dossiers contenant des données personnelles ou de santé sans précaution. Anonymisez, et coupez l'entraînement sur vos données dans les réglages de confidentialité.

Astuce : laissez Claude vous configurer

Pas envie de tout remplir vous-même ? Collez ce message dans une nouvelle conversation :

Aide-moi à configurer mon assistant. Pose-moi 5 questions pour cerner
mon métier, mes besoins et mon style, puis propose-moi :
1) un texte d'instructions personnelles à coller dans mes réglages,
2) la liste des Projets utiles à créer,
3) les connecteurs qui me feraient gagner du temps.

4. Le Projet : votre meilleur allié

C'est la fonction qui change tout. Un Projet est un espace fermé où vous déposez une seule fois votre contexte (votre métier, votre style, vos documents de référence). Ensuite, chaque conversation lancée dedans réutilise ce contexte automatiquement.

Le secret n'est pas le prompt, c'est le contexte. Plutôt que de tout réexpliquer à chaque fois, vous créez un Projet par grand domaine (ex. « Mon activité », « Ma formation », « Mes contenus ») et vous y travaillez. Résultats plus justes, plus constants, et beaucoup moins d'effort.

Règle d'or : un assistant bien configuré vaut mieux que dix prompts géniaux. Investissez 20 minutes dans un bon Projet, vous les récupérez chaque semaine.

5. Claude AI, Cowork, Code : quand utiliser quoi

Vous voulez…Utilisez
Écrire, analyser un document, créer un assistant, poser des questionsClaude (web & appli)
Réorganiser des fichiers, créer/éditer des docs en lot sur votre ordi ou votre DriveClaude Cowork
Créer un site, un script, une automatisation techniqueClaude Code

En pratique : commencez tout sur Claude web. Passez à Cowork le jour où vous avez un gros ménage de fichiers à faire, et à Code seulement si vous mettez les mains dans la technique.

Et Claude Design ? Ce n'est pas un quatrième Claude : c'est un mode dans Claude web (claude.ai/design) qui génère présentations, maquettes et prototypes visuels à partir d'une simple description, exportables vers Canva, PDF ou PPTX. En aperçu, sur les offres payantes — à découvrir le jour où vous avez du visuel à produire.

6. Commandes & réflexes utiles

Quelques commandes (surtout dans Claude Code / le terminal)

CommandeCe qu'elle fait
/compactRésume la conversation pour libérer de la place quand elle devient longue (et garde l'essentiel)
/clearRepart sur une conversation propre
/modelChange de modèle (Opus / Sonnet / Haiku)
/helpAffiche les commandes disponibles

Les réflexes qui font la différence

  • Un sujet = une conversation (ou un Projet). Évitez les conversations fourre-tout qui s'alourdissent.
  • Déposez le contexte dans un Projet plutôt que de tout recoller à chaque fois.
  • Conversation trop longue / qui rame ? Faites /compact (dans Code) ou démarrez une nouvelle conversation.
  • Relisez toujours ce que Claude produit : il se trompe parfois. Sur des sujets sensibles (santé, juridique), vérifiez.
  • Confidentialité : coupez l'entraînement sur vos données, et n'y mettez pas d'informations sensibles non anonymisées.
L'interface et les fonctions de Claude évoluent vite. Ce guide reflète l'état de juin 2026 — si un menu a bougé, fiez-vous au libellé le plus proche.

7. Pour aller plus loin — ressources officielles

Tout est gratuit et officiel (Anthropic). De quoi approfondir à votre rythme.

  • Documentation officielle — docs.claude.com (et code.claude.com/docs pour Claude Code).
  • Centre d'aide — support.claude.com : les étapes détaillées et à jour de chaque fonction (mémoire, projets, connecteurs…).
  • Anthropic Academy (formations gratuites, un simple e-mail suffit) — anthropic.skilljar.com. Pour débuter sans coder : Claude 101 puis AI Fluency ; pour l'assistant fichiers : Introduction to Claude Cowork ; pour la technique : Claude Code 101.
  • Skills officiels (GitHub) — github.com/anthropics/skills (exemples prêts à l'emploi) ; le standard ouvert : agentskills.io.
  • Annuaire des connecteurs — claude.com/connectors (plus de 50 intégrations).
